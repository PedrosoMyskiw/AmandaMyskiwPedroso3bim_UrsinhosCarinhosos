# 🧸💖 Loja Ursinhos Carinhosos

Projeto de uma loja temática inspirada no universo dos **Ursinhos Carinhosos**, desenvolvido como atividade acadêmica.

## 📖 Sobre o projeto

A aplicação simula o sistema de uma loja especializada em produtos temáticos dos Ursinhos Carinhosos. O projeto foi desenvolvido com o objetivo de praticar conceitos de **banco de dados, SQL e organização de informações**, utilizando uma temática divertida e personalizada.

O sistema possui informações relacionadas a produtos, funcionários, cargos, formatos de produtos e demais dados necessários para representar o funcionamento de uma loja.

## 🧸 Temática

A identidade do projeto foi inspirada nos **Ursinhos Carinhosos**, utilizando personagens, produtos e elementos relacionados ao universo da franquia para criar uma loja temática.

## 🗃️ Banco de Dados

O projeto utiliza um banco de dados relacional para armazenar e organizar as informações da loja.

Entre os dados trabalhados estão:

- 🧸 Produtos e pelúcias
- 👩‍💼 Funcionários
- 💼 Cargos
- 📦 Formatos dos produtos
- 💰 Informações relacionadas às vendas
- 🏪 Informações da loja

## 🛠️ Tecnologias utilizadas

- PostgreSQL
- SQL
- Git
- GitHub
